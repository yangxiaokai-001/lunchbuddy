# 上班陪伴 Web 页面线框图初稿

## 1. 页面结构总览

第一版建议包含 5 个核心页面：

1. 登录/注册页
2. 首页
3. 群组页
4. 打卡记录页
5. 个人设置页

信息架构建议：

```text
登录/注册
   ↓
首页
   ├─ 群组页
   ├─ 打卡记录页
   └─ 个人设置页
```

## 2. 登录/注册页

### 2.1 页面目标

帮助用户快速进入产品，减少首次使用门槛。

### 2.2 线框结构

```text
+------------------------------------------------------+
| Logo / 产品名：牛马上班搭子                           |
| 一句短文案：今天也一起上班吧                          |
|                                                      |
| +-------------------+  +---------------------------+ |
| | 牛马上班插画区     |  | 登录 / 注册卡片           | |
| |                   |  | 邮箱输入框                | |
| |                   |  | 密码输入框                | |
| |                   |  | [登录] [注册]             | |
| |                   |  |                           | |
| |                   |  | 可选：继续使用 Google 登录 | |
| +-------------------+  +---------------------------+ |
+------------------------------------------------------+
```

### 2.3 关键说明

1. 左侧是情绪化主视觉，建立产品记忆点。
2. 右侧表单尽量简单。
3. 首版只保留邮箱登录即可。

## 3. 首页

### 3.1 页面目标

首页是最核心页面，用户每天打开后能在这里完成：

1. 看今天的牛马状态
2. 选择今日心情
3. 打卡
4. 看下班倒计时
5. 快速进入群组和外卖转盘

### 3.2 线框结构

```text
+--------------------------------------------------------------------------------+
| 顶部导航                                                                       |
| Logo | 首页 | 群组 | 打卡记录 | 设置 | 用户头像                                |
+--------------------------------------------------------------------------------+
| Hero 区                                                                        |
| +----------------------------------+  +--------------------------------------+ |
| | 牛马上班场景背景                  |  | 今日状态面板                         | |
| |                                  |  | 今日日期                             | |
| | 牛马角色（表情随心情变化）        |  | 当前心情：普通营业                   | |
| |                                  |  | 上班状态：已打卡 / 未打卡            | |
| | 陪伴文案                         |  | 距离下班：03:21:18                   | |
| +----------------------------------+  | [上班打卡] [下班打卡]                | |
|                                       +--------------------------------------+ |
+--------------------------------------------------------------------------------+
| 功能区                                                                          |
| +----------------------------------+  +--------------------------------------+ |
| | 今日心情                          |  | 群组快捷入口                         | |
| | [干劲满满] [普通营业]             |  | 当前群组：前端摸鱼搭子               | |
| | [累了] [想吃点好的] [快下班吧]    |  | 成员数：6                            | |
| | 选择后牛马表情立即变化            |  | [进入群组] [加入其他群组]            | |
| +----------------------------------+  +--------------------------------------+ |
| +----------------------------------+  +--------------------------------------+ |
| | 今日推荐 / 最近转盘结果            |  | 今日摘要                             | |
| | 上次转盘：黄焖鸡米饭               |  | 上班时间：09:12                      | |
| | [再转一次]                        |  | 下班时间：未打卡                     | |
| | [查看外卖池]                      |  | 今日心情：普通营业                   | |

+--------------------------------------------------------------------------------+
```

### 3.3 首页重点

1. 视觉焦点必须是牛马角色，而不是一堆卡片。
2. 打卡和倒计时要非常突出。
3. 群组外卖入口要靠近首页，不要埋太深。

## 7. 移动端适配建议

第一版虽然以桌面端为主，但建议保证手机基础可用。

### 7.1 首页移动端布局

```text
顶部导航简化为：
[Logo] [群组入口] [头像]

模块从上到下堆叠：
1. 牛马角色区
2. 今日状态区
3. 打卡按钮区
4. 心情选择区
5. 最近外卖结果区
```

### 7.2 移动端重点

1. 心情按钮要足够好点。
2. 打卡按钮要固定明显。
3. 转盘动画在手机上也要完整可见。

## 8. 页面优先级建议

建议按这个顺序设计和开发：

1. 首页
2. 登录/注册页
3. 群组页
4. 设置页
5. 打卡记录页

原因：

1. 首页决定产品气质。
2. 首页先做出来，最容易验证“陪伴感”是否成立。
3. 群组页是第二核心玩法。

## 9. 设计提醒

1. 首页不要做成普通后台面板。
2. 牛马角色要有存在感，不能只是一个小插图。
3. 情绪化区域和功能区要平衡，既要可爱，也要好用。
4. 打卡、倒计时、外卖转盘三个行为入口必须很快找到。
